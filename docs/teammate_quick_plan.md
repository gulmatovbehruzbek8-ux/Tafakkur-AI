# 🚀 Project "UniAI" - Quick Hackathon Plan

**The Pitch:** A privacy-first, locally-hosted AI platform for universities. We are solving **three** priority hackathon problems at once by giving students an AI tutor, professors an AI grader, and admins an AI announcement generator. All data stays local!

## 🛠️ Tech Stack
* **AI Engine:** Ollama (Llama-3 or Qwen) + FAISS (for document search)
* **Backend:** FastAPI (Python)
* **Frontend:** Next.js (or Streamlit if we need to move faster)

## ✨ MVP Features (What we demo on Final Day)
1. **The Principal View**: Type 3 bullet points → AI generates a formal university news post.
2. **The Professor View**: Upload a syllabus/rubric → AI automatically grades a student's assignment and suggests a score.
3. **The Student View**: Read the news, submit assignments, and chat with an AI Tutor that *actually knows the syllabus*.

## 👥 Who Does What?
* **AI/Backend Dev(s):** Run Ollama, build FastAPI routes, set up the RAG (document chat) logic.
* **Frontend Dev(s):** Build the 3 dashboards, connect to the API, make it look beautiful.
* **Pitch/PM:** Write the slide deck, generate fake "student data" for the demo, prepare for Checkpoints 1 & 2.
